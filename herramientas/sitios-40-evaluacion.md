# 40 sitios web — evaluación para Dirsi y Antonio

Origen: infografía "40 sitios web que Google no quiere que conozcas" (oct 2026).
El título es marketing: ninguno de estos sitios está oculto por Google, todos
están indexados. Evaluación del 27 oct 2026.

## Uso directo por Dirsi (la IA)

Estos sí los puede usar Dirsi en nombre de Antonio, porque aportan datos o
verificación que Dirsi no tiene por sí misma:

- **VirusTotal**: escanear un archivo sospechoso antes de abrirlo.
- **Have I Been Pwned**: comprobar si un correo salió en filtraciones.
- **Archive.org / Wayback Machine**: recuperar versiones antiguas de páginas.
- **Archive.ph**: captura permanente de una fuente; la evidencia capturada no
  cambia después, lo que encaja con la regla de evidencia de este repo.
- **Semantic Scholar**: búsqueda académica legal, con API disponible.
- **Gutenberg**: libros de dominio público, legales.
- **WolframAlpha**: cálculo y datos (vía API).
- **Elicit, Consensus, Connected Papers, SciSpace**: investigación académica;
  nivel gratis con límites (consultas o grafos al mes).
- **Summarize.tech**: resumir vídeos para estudiar; verificar antes de citar,
  porque un resumen de IA puede inventar contenido.

## Útiles para Antonio, no para Dirsi

Dirsi hace estas operaciones con código directamente (comprimir, quitar
fondos, generar mockups, probar regex), más rápido y sin depender de una web.
Para Antonio son atajos sin instalar nada:

- **Kickresume**: feedback de CV; lo revisa él, no la IA.
- **Photopea, Squoosh, Remove.bg, Unscreen, Cleanup.pictures, Carbon, Ray.so,
  Shots.so, SmartMockups**: edición de imágenes, mockups y capturas de código.
  Ojo: el nivel gratis de varios es baja resolución, con marca de agua o con
  créditos contados.
- **Regex101**: probar expresiones regulares (Dirsi las verifica con código).
- **MyNoise, Music for Programming, Coffitivity**: concentración al programar.
- **JustWatch, Radio Garden, EveryNoise, TuneFind**: ocio.
- **Temp-Mail, File.io, Privnote**: solo para cosas desechables; nunca cuentas
  de trabajo, recuperaciones ni secretos.

## No usar (ni Dirsi ni Antonio)

- **LibGen, Sci-Hub, PDFdrive**: libros y artículos pirateados. Además del
  tema legal, viven de anuncios agresivos y espejos dudosos (riesgo de
  malware), y mezclarlos con un perfil profesional es una mancha innecesaria.
  Lo que aportan lo cubren legalmente Gutenberg, Archive.org y Semantic
  Scholar.

## Regla general

Lo que Dirsi puede hacer con código no necesita una web. Lo que sí necesita
de fuera son fuentes y verificadores: archivos, artículos, filtraciones y
capturas permanentes.
